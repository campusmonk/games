Lock & Key Memory Game

Directional Doors: Some doors only open from one side!

Game Rules:
  • Start at the dark center square (👤).
  • Doors are one-way or locked from specific directions.
  • Hitting a locked door bounces you back to the level start.
  • Collect key 🔑 first, then head to the exit door 🚪.
  • Use arrow keys, WASD, or the on-screen arrows to move.
